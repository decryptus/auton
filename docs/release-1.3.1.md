# auton 1.3.1

The optional Textual interface now uses a turquoise and orange palette, including
its navigation, tables and dialogs. It requires DWho 0.3.66 or newer.

Keyboard shortcuts, collection and execution behavior are unchanged. Accepted
requests stay blue, running work is labeled distinctly, confirmed success is
green, warnings are amber, and failures are red.

Upgrade with `python -m pip install --upgrade "auton[textual]==1.3.1"`.
No configuration or stored-data migration is required.

See the [Textual guide](textual.md) for controls and synthetic examples.
