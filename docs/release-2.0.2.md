# auton 2.0.2

Packaging-only release, with no change to Auton's behavior or configuration.

- The Docker image installs the `autond` wheel and no longer contains the
  repository sources, tests, documentation sources or maintainer files.
- The `auton` and `autond` source distributions no longer include the test
  suites or development scripts.

Upgrading is optional. Pull the new image or reinstall the package as usual.

## Français

Version de packaging uniquement, sans changement de comportement ni de
configuration. L’image Docker installe la wheel `autond` et ne contient plus les
sources du dépôt, les tests, les sources de documentation ni les fichiers de
maintenance. Les distributions source `auton` et `autond` ne contiennent plus les
suites de tests ni les scripts de développement. La mise à jour est facultative.
